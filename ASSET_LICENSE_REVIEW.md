# Asset and ownership review required before public distribution

The repository has an approved MIT license for its original software code, but does not yet provide a complete provenance record or public reuse license for game artwork and other creative content. The project owner must confirm distribution rights for these bundled categories before publishing:

- `cat_society/assets/menu/frame_*.jpg` — 256 menu animation frames.
- `cat_society/assets/dialogue_photos/*.png` — 21 portrait crops derived from the in-game animal artwork.
- `cat_society/assets/sfx/water_splash.mp3` and `water_splash.wav`.
- The original art, character/animal designs, authored text and story, prerecorded media, and other creative content represented by the procedural rendering and sound systems (the original implementation code is separately MIT-licensed).
- The Bal's Sound Garden name, logo treatment, and ABProjects attribution.

No standalone font files are bundled in `cat_society/assets` in this release.

Third-party Python packages have separate licenses and notices described in `THIRD_PARTY_NOTICES.md`. A Windows executable distributor must also retain the license files supplied by the exact Pygame, NumPy, SciPy, Python, and binary dependency versions used for that build.

This document records unresolved rights/provenance checks for creative assets. It does not cancel the MIT grant for original source code, establish asset ownership, or grant an additional creative-asset license.
